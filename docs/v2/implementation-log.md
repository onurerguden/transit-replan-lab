# v2 implementation log

Each entry records completed acceptance checks and concrete blockers.

## F0 · Baseline and guardrails

- Work happens on `feat/v2-engineering` in the existing review worktree, created from
  `origin/main` (`1dfe799`). A separate worktree was unnecessary because the review branch was
  already merged and its tree matches the baseline.
- [Baseline](baseline.md) recorded: 74 deterministic tests, 87% branch coverage across `trl`,
  demo search p50 386 ms.
- [`test_v2_defects.py`](../../backend/tests/test_v2_defects.py) records 27 reproduced defect
  cases as strict expected failures and one guard that passes.
- `trl.settings` validates every environment variable. The API is created by a factory
  (`uvicorn --factory trl.api.app:create_app`). The database default no longer depends on the
  working directory.
- One version source: `2.0.0.dev0` in the package metadata, the API schema and the frontend
  package, checked by `test_versions_have_one_source`.
- Lint now covers complexity, blind excepts, async blocking, security and pytest style.
  Exceptions are listed per file with the phase that removes them. Production asserts became
  explicit errors.
- Branch coverage spans all of `trl` with a floor of 86%, ratcheting to 90%.
- `make test` is hermetic. `make test-ollama`, `make test-deep` and `make api-drift` are new.
- CI is split into backend (Ubuntu and macOS), frontend, browser and Docker, and a nightly deep
  job. Actions are pinned by commit SHA, caches are enabled, and browser traces upload on failure.
  Dependabot covers actions, uv and npm.

## F1 · Closure semantics and independent verifier

- Specified occupancy in [`closures.md`](../semantics/closures.md) and recorded ADR 0010.
- `trl.verifier` (reference timetable protocol, `IncidentState`, presence intervals, checks) shares no code with routing. Three import contracts enforce independence, a ban on overlay imports, and layering. `trl.verify` is a thin adapter.
- The router no longer waits through closures (departure pruning and a bounded wait before walks). The existing walking-window oracle was updated to the occupancy rule.
- A new Hypothesis oracle enumerates journeys on random networks (mid-trip boarding, pickup and drop-off flags, closures, a cancellation, a delay, wait limits). The router's optimum matches, 38% of generated cases are feasible, every emitted offer verifies, and a one-second mutation is rejected.
- An exhausted initial search is stored as `search_incomplete` (V2-L1). V2-C5 passes.
- `trl route --scenario demo` output is byte-identical to v1.2.0.
- Frozen copy of the label search: `backend/tests/label_search_oracle.py`.

## F2 · Lifecycle and persistence

- Transition table (`trl.lifecycle`), validated updates, `system_error`, retryable codes and
  the `retry` command (V2-L2). Illegal commands return 409 problem details.
- Numbered migrations with backup and integrity checks (V2-L4). A fixture generated by running
  the v1.2.0 release code (`scripts/make_v1_2_fixture.py`) upgrades with identical views,
  events and receipts, and an upgraded clarification can still be answered.
- Incident sets with add, replace and retract (V2-C6); a retraction replans without reading a
  report.
- Leases with fencing tokens replace the file lock; supersede cancels the older task; the
  heartbeat loss path exits cleanly (ADR 0011). Reliability tests now use a one second TTL.
- Checkpoints moved to their own database and are pruned. Blocking store calls left the event
  loop. The SSE stream wakes on commits, polls every two seconds for other processes, sends a
  retry hint and stays open through clarification.
- Three clarification rounds (V2-L6), RFC 9457 problem details for every error including
  404, 405, 422 field errors and 500, and a `Location` header on run creation.
- `trl db migrate|check|backup|restore|prune`.
- Stateful Hypothesis test over create, disrupt, retract, retry, replay, conflict, restart and
  stale writers, with database, lease, vote and incident invariants. `make test-deep` runs a
  long version.
- Deviation from the plan: `Create` idempotency stays globally scoped because
  the service has no client identity.

## F3 · Feeds, catalogue and footpaths (partial)

- ESHOT (`bus.zip`, 18.4 MB) and İZBAN (`izban.zip`) are pinned with checksums. İzdeniz returns an HTML page, so it is recorded as unavailable. The portal license page confirms CC BY 4.0.
- `trl.feeds` and `trl feeds --write` produce `data/gtfs/health.json` (counts, calendar coverage, quarantined trips, assumptions). ESHOT and İZBAN calendars do not cover 2026-10-21, so their weekly patterns are projected and labelled as assumptions.
- `trl.catalogue` lists 11,857 stops. `trl.timetable.footpaths` generates 119,834 links in 0.3 s. The buffer on every link keeps the table closed under the triangle inequality, so no Dijkstra closure is needed. The documented interchanges keep 480 s.
- `trl.language.gazetteer` resolves stop names with Turkish case suffixes, partial names and mode words.
- Not done: wiring the gazetteer into intake (F5), a `TRL_NETWORK` setting and ADR 0013. F4 to F11 are not started.

## F5 · Language layer and evidence gate

- `trl.language.timeexpr` and `clauses` back both parsers. All defect markers in
  `test_v2_defects.py` are removed: C1–C4, C7, L6–L9 now pass as plain regressions.
- Verified-quote gate replaces the eight-phrase whitelist. Quotes need four characters, a unique
  whole-word match and an unblocked clause. Prompt text is part of the request digest.
- Conjoined stops become separate incidents. Property tests cover round trips and gate
  soundness; `make test-deep` runs 20,000 adversarial quotes.
- Changed behavior: `10:00 pm` after an unmarked start carries to the start, fractional and mixed
  duration units are read, `GMT+3` counts as local time.
- Natural-language trip references (stop plus departure time) were added after the first cut, see the addendum.

## Addendum · independent reference for the full network

- `trl.verifier.sqlite_reference` loads the raw archives into an indexed SQLite database with its own reader and its own calendar rule and serves trips and stops on demand. A deep test routes random full-network queries and verifies every emitted plan against it. It shares no code with the router or the compiled arrays. The weekly projection for ESHOT and İZBAN is applied by the same stated policy.

## Addendum · trip references and the interface split

- `trl.language.trips` resolves a stop plus a departure time to one trip. A property-style test builds the report in English and Turkish for hundreds of unique departures and checks the resulting incident. An unknown departure names no trip.
- `App.tsx` went from 391 to 236 lines, with the plan, offer evidence, timeline and formatting helpers in their own modules. Unit and browser suites are unchanged.

## Addendum · adapter seeds

- Two more seeds (43, 44) were trained and scored on the same 600 reports: 77.7% and 76.8% against 59.5% for seed 42. The adoption rule, registered earlier on a dev set where every arm is perfect, is unchanged, so the adapter is still not adopted.

## Addendum · second-family paraphrases

- `llama3.2:3b` (the installed Ollama is too old for Gemma) rewrote the first 300 test groups through placeholders. 438 reports passed validation. Arms were registered before they read them. Results are in `experiments/results/v2/bench-paraphrase`. Without a judge model the labels are noisy where the rewrite dropped a negation, a hedge or a time zone, and the report says so.

## Addendum · second router

- `experiments/bench_v3/reference_router.py` is a time-dependent Dijkstra over stops that shares no code with the label search. With loose limits and no closures the label search never beat it, and matched its earliest meeting in at least 95% of 40 random core scenarios (deep test). It is a lower bound check on core scenarios. It does not produce plan labels for the benchmark, which scores report reading and clarification.

## Addendum · full-size model run

- The three adapter seeds read all 2,000 test reports: 59.6%, 80.3% and 78.5% against 53.8% for rules, with no unsupported incident. This run uses the final reader and is labelled as an extension of the preregistered subset run.

## Addendum · the full network behind the API

- `POST /v1/route` serves meeting queries on the core or the full network (`TRL_NETWORK`). It loads the compiled arrays once, bounds each query, returns offers or an explicit `search_incomplete`, and rejects unknown stops with a problem response. Runs themselves still use the core schedule.

## Addendum · dispatcher

- Workers no longer spin on a contended lease. One dispatcher loop per process scans planning runs, skips those another live worker holds with a read-only check, and starts the rest. The process-death and lease tests, the state machine (60 examples of 20 steps) and the browser suite pass unchanged.

## Addendum · fast mode

- An opt-in dominance across arrival times at non-destination stops, skipped when closures exist. Differential tests against the exact search agree on the best offer's rank. On the full network it removes the incomplete outcomes (13 of 40 become 0) and reaches p95 1.49 s. Compilation now switches off trips with backwards times, which a fast-mode benchmark exposed through a verifier rejection.

## Addendum · kept alternatives

- Fast mode drops a label only after `alternatives` earlier labels that end on different trips cover it. At three, the top six rank keys match the exact search in 39 of 39 random core scenarios with 62% of the work. On the full network that setting is slower (p95 8.5 s, 3 of 40 incomplete), so the API defaults to one.

## Addendum · human review packet

- `scripts/export_review_packet.py` and `scripts/review_agreement.py` turn the independent-annotation step into two commands: a blind packet of 200 test reports with the key kept apart, and Cohen's kappa plus a disagreement list for two filled copies. Tests use a perfect annotator and a copy to check the arithmetic. No annotator has filled the packet.

## Addendum · Operator adapter v3

- TRL-Bench v3.1 replaced the small v3 phrase banks for training: 3,859 distinct masked train templates against about 280, split-owned frames and connectives, and test parts from Llama 3.2 3B that the maintainers did not read. The gold-quote check found a reader gap (`17.11.2026:` was not read as a date) and parts the reader could not bind, which were fixed or dropped.

- A real-model hybrid test (`test_real_vnext_hybrid_grounds_a_report_and_recovers_a_meeting`) returns a clarification with the current Ollama and base model, with and without the schema change. It was not investigated further.
